# `protobuf.decode`

Decodes a field's raw data in the Confluent Protobuf format.

## Description

The processor takes raw data (bytes or a string) in the specified field and decodes
it from the [Confluent Protobuf wire format](https://docs.confluent.io/platform/current/schema-registry/fundamentals/serdes-develop/index.html#wire-format)
into structured data. It extracts the schema ID from the data, downloads the associated schema from the
[schema registry](https://docs.confluent.io/platform/current/schema-registry/index.html),
resolves the schema's references and decodes the payload. The schema is cached locally after it's first compiled.

The wire format is a magic byte (`0x00`), a 4-byte big-endian schema ID, a message index (a
zigzag-encoded varint that selects the message type within the schema), and the protobuf-encoded message payload.

If the processor encounters structured data or the data can't be decoded it returns an error.

This processor is the counterpart to the Protobuf encode capability, mirroring the schema handling of `avro.decode`.

If decoding fails, the processor returns a stable error code:

- `processor.protobuf_decode.schema_compile` — the Protobuf schema failed to compile.
- `processor.protobuf_decode.reference_resolve` — a schema reference (import) could not be resolved, or the reference graph forms a cycle.
- `processor.protobuf_decode.message_index` — the Confluent message-index prefix is malformed or out of range.
- `processor.protobuf_decode.unknown_field` — the payload carries a field the schema does not declare.
- `processor.protobuf_decode.wire_format` — the payload is not valid Protobuf wire format for the schema.

### Decode a record field in Confluent Protobuf format

This example shows the usage of the `protobuf.decode` processor.
The processor decodes the record's`.Key` field using the schema that is downloaded from the
schema registry and needs to exist under the subject`example-decode`. In this example we use
the following schema:

```proto
syntax = "proto3";
message record {
  string myString = 1;
  int32 myInt = 2;
}
```
